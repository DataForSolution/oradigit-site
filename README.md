# OraDigit legacy website snapshot

> [!IMPORTANT]
> This repository is a historical snapshot. It is **not** the production source
> for OraDigit and must not be used for deployment or support.

The active OraDigit website and platform are maintained in a private repository
and deployed through the production Firebase infrastructure. This public
snapshot is retained only for historical provenance.

The custom-domain, Firebase deployment, and repository automation configuration
have been removed to prevent this snapshot from being mistaken for an active
deployment source. Do not publish, deploy, or operate services from this
repository.
